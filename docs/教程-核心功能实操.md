# PaperForge 核心功能实操教程

> **这份文档写给谁**：第一次打开 PaperForge、想把论文库真正用起来的人。
> **读完能做什么**：完整走通「导入 → 检索 → 问答 → 写作 → 深度审稿」五条主线，
> 并知道每条线上「结果怎么读」「哪里容易误判」。
>
> 界面里也有同一份内容：右上角 **?** 按钮打开「帮助中心」。首次进入时还会自动
> 弹一次 6 步引导，跳过之后可以随时在帮助中心重看。
>
> 每节统一给三块：**怎么做** / **你会看到什么** / **常见误区**。若只想排错，
> 直接跳到文末的[速查表](#附常见误区速查表)。

## 0. 先把服务跑起来

PaperForge 是「本地后端 + 网页前端」的结构，前端只是界面，**所有数据和模型调用都在你自己机器上**。

Windows 下最省事的方式：双击项目根目录的 `start_paperforge.bat`，脚本会自动找项目根、
拉起后端并打开浏览器。其他启动方式（桌面版 exe、开发者模式、Docker Compose）见
`README.md` 的「快速启动」一节。

**你会看到**：浏览器打开 `http://localhost:8770`，首页顶部是「研究库索引」统计区，
下面是搜索栏与论文列表。右上角显示版本号。

**常见误区**：只开了前端（`cd web && npm run dev`）没开后端，页面能打开但列表永远是空的。
判断方法：首页统计卡的数字全为 0 且刷新无变化，通常是后端没起。

## 1. 导入论文

一切功能都建立在你自己的论文库上，所以第一步是把 PDF / DOCX 收进来。

### 怎么做

1. **拖拽上传**：在首页「上传论文」区域把 PDF / DOCX 拖进去，或点击选择文件。
2. **从 arXiv 导入**：已知 arXiv ID 或标题时，用上方的 arXiv 导入区直接抓取，
   省掉「先下载再上传」这一步。
3. **等索引建好**：导入后系统会自动提取标题、作者、摘要，并建立全文索引。
   每篇论文卡片底部会显示「文本块数量」和「索引大小」。

### 你会看到什么

- 论文卡片出现在列表里，卡片底部显示 `N 个文本块` 与索引体积（如 `1.2 MB`）。
- 刚导入时这两个值是 `0 个文本块 / 0 B`，索引完成后变成实际数值。
- 索引未完成的论文，那个「0 个文本块」会显示为**橙色虚线下划线**，鼠标悬停会说明原因。

### 常见误区

- **刚导入就做语义搜索，搜不到** —— 不是导入失败，是索引还没建完。先切「关键词」模式（见下一节）。
- **扫描版 PDF 搜不到正文** —— 扫描件没有文字层，必须先 OCR。界面会对这类论文给 OCR 入口。
- **以为要把论文复制到某个目录** —— 不需要。通过界面导入即可，文件与元数据都由系统管理。

## 2. 检索：三种方式怎么选

同一个搜索框有三种找法。**选错方式，会以为「库里没有」，其实只是没搜对。**

### 2.1 关键词搜索（FTS5）

| | |
|---|---|
| **怎么做** | 搜索栏右侧模式开关切到「关键词」，输入术语、作者名或 arXiv ID |
| **依赖** | 不依赖向量索引 |
| **什么时候用** | 已知确切术语/作者；刚导入完想立刻确认论文在不在库里 |

**你会看到**：按字段精确匹配的结果，排序稳定、可预期。

**常见误区**：用自然语言长句（「这些论文是怎么处理长尾分布的」）去搜关键词，
几乎必然搜不到——关键词模式匹配的是词，不是意思。

### 2.2 语义搜索

| | |
|---|---|
| **怎么做** | 模式开关切到「语义」，用自然语言或近义表述搜索 |
| **依赖** | 需要全文向量索引（导入后自动建立，需要时间） |
| **什么时候用** | 记不清原文用词，只想按意思找 |

**你会看到**：按语义相关性排序的结果。例如搜「参数高效微调」，
只写 LoRA 而没有出现这个词的论文也能命中。

**常见误区**：

- **语义搜不到 = 论文不存在？** 不一定。先切回关键词确认论文在库里。
  绝大多数「语义搜不到」是索引未完成。
- **索引没建完能不能先用？** 能。切关键词模式即可，两者互不影响。

### 2.3 图检索

| | |
|---|---|
| **怎么做** | 进入「图检索」页，输入你想找的图里出现过的文字（如指标名、坐标轴标签） |
| **依赖** | 该图需完成 OCR 且文字向量化成功 |
| **什么时候用** | 想定位「某张图里出现过这个指标」 |

**你会看到**：命中的图（含所属论文、页码、图中 OCR 文字、相似度），可点开原图。

**常见误区（重要）**：

> 图检索匹配的是**图里 OCR 出来的文字**，不是对图内容的语义理解。
> 也就是说，搜「accuracy」能找到坐标轴写着 accuracy 的图；
> 但搜「训练不收敛的图」不会命中——那是模型对图意的理解，目前不提供。

## 3. 问答：答案只来自你的库

这是 PaperForge 和通用 AI 最大的区别：**它只依据你库里的论文作答，库里没有的内容不会编造。**

### 怎么做

1. **选定范围**：可以全库提问；也可以在首页勾选若干篇论文后，只针对这几篇提问。
2. **用自然语言提问**：例如「这几篇在处理长尾分布时分别用了什么策略」。
   问题越具体，越容易拿到可用的对比。
3. **核对引用来源**：每条回答都带引用来源，点开可以回到原文段落核对。

### 你会看到什么

- 回答以流式方式逐字出现（不用等整段生成完）。
- 回答下方列出引用的论文与段落。
- 库中确实没有依据时，它会**明确说明无法回答**，而不是给一个像模像样的假答案。

### 常见误区

- **「无法回答」不是故障**，而是在拒绝编造。换成库里有覆盖的问法，或先导入相关论文。
- **未配置模型时问答不可用** —— 此时页面会给出「3 步配好模型」的引导。
  但注意：**检索、图检索、深度审稿不依赖生成模型**，没配模型也能用。
- **不要跳过核对引用**。引用可点开正是这个工具的价值所在。

## 4. 写作工作台

从大纲到成稿，**引用只能从你的库里选**，因此不会出现「编造的参考文献」。

### 怎么做

1. **新建项目**：在「写作」页新建项目，设定题目与目标结构，作为后续生成的约束。
2. **先生成大纲**：先定大纲，再逐章展开。
3. **逐章写作**：每章可单独生成或改写；插入引用时从库里选择，引用条目随文保存。
4. **导出**：支持导出 **Markdown / Word / LaTeX**；参考文献可走 CSL 面板导出
   （BibTeX、LaTeX、HTML、纯文本、CSL JSON 等），方便直接喂给 Zotero / Word / LaTeX。

### 你会看到什么

- 章节编辑器：左侧大纲、右侧正文，可来回切换。
- 引用列表里的每一条都来自你自己的库，可追溯到具体论文。
- 导出前会弹出预览，确认后再下载。

### 常见误区

- **未配模型 = 写作页完全不能用？** 不是。正文生成不可用，但**大纲、引用插入、导出都正常**。
  可以先搭结构、先把引用插好，配好模型再生成正文。
- **把生成内容直接当终稿** —— 生成的正文仍需你自己核对事实与表述，它只是加速起草。
- **担心参考文献造假** —— 引用来自你的库，不存在凭空生成条目；但仍建议导出前扫一眼引用列表。

## 5. 深度审稿（DEPTH v4.2）

用四维评分 + 多轮「质疑 / 辩护 / 主席裁决」给一篇论文出评审意见。

> 先建立正确预期：**分数是「审稿视角下的可用性评估」，不是论文好坏的唯一标准。**
> 它的用途是帮你快速发现「这篇哪里可能站不住」，而不是给论文打分排名。

### 怎么做

1. **选论文并提交**：首页选中一篇或多篇，点「V4 深度审稿」。
   多篇会排队依次处理，进度显示在「研究脉搏」卡片上。
2. **等结果**：审稿包含多轮模型调用，单篇通常需要数分钟。
3. **读结果**：在结果页看四维得分、质疑点、辩护与裁决理由。

### 评分怎么读

**四个维度**（各 0~1 分，雷达图展示）：

| 维度 | 看的是什么 |
|---|---|
| 创新性 | 相对已有工作有没有新东西 |
| 严谨性 | 论证、实验、统计是否站得住 |
| 影响力 | 对领域的潜在影响 |
| 可复现性 | 方法描述是否足以复现 |

**权重随论文类型变化**——同一个分数，在不同类型论文里含义不同：

| 论文类型 | 权重倾向 |
|---|---|
| 理论突破 | 最看重**创新性** |
| 方法改进 | 最看重**严谨性** |
| 应用迁移 | 更看重**影响力**与**可复现性** |
| 综述 | 相对均衡 |

另外，**模型对类型判断越不确定，权重越向各类型平均值靠拢**。
这是刻意的设计：类型没把握时，不押注在某一维上。

**裁决四档**：`接收 Accept` / `小修 Minor Revision` / `大修 Major Revision` / `拒稿 Reject`。

**一票否决**：需要**至少 3 条「致命缺陷」**才触发（阈值可配置）。
单条致命缺陷不足以直接拒稿——这是为了避免模型一次误判就把一篇好论文否掉。

### 你会看到什么

- 论文卡片上显示**综合分（0~100）**；悬停可看裁决与致命缺陷数。
- 结果页有：雷达图、四维得分、论文类型判断、质疑点列表、作者辩护、主席裁决理由。
- 裁决理由会说明最终档位是怎么来的（是分数落在哪一档，还是触发了降级）。

### 常见误区

- **分数低 = 论文差？** 不一定。先看**质疑点是否成立**。
  质疑点里区分「致命缺陷」与「一般问题」，后者（如消融实验缺失、缺少某些基线对比）
  是常见局限，不代表结论错误。
- **没配模型能用吗？** 不能——审稿本身依赖模型。但这是唯一强依赖模型的核心功能，
  其余功能照常。
- **把审稿意见当定论** —— 它是辅助你自查的工具，最终判断权在你。

## 附：常见误区速查表

| 现象 | 真正的原因 | 怎么办 |
|---|---|---|
| 页面能开，论文列表永远为空 | 后端没启动 | 用 `start_paperforge.bat` 启动，确认后端在 8770 端口 |
| 刚导入的论文语义搜索搜不到 | 全文索引未完成 | 切「关键词」模式先搜；卡片上橙色虚线下划线即索引未完成 |
| 语义搜索一直无结果 | 索引未完成，或向量依赖不可用 | 先用关键词确认论文在库；检查后端日志 |
| 关键词搜不到自然语言长句 | 关键词模式按字段匹配词，不匹配语义 | 长句改用语义搜索 |
| 图检索搜「某类图」搜不到 | 图检索匹配图中 OCR 文字，不理解图意 | 改用图中实际出现的文字（指标名、标签） |
| 问答说「无法回答」 | 库中没有依据，系统在拒绝编造 | 换问法，或先导入相关论文 |
| 问答 / 综述 / 写作不能生成 | 未配置模型 | 设置 → 模型管理；检索与深度审稿不受影响 |
| 写作页不能生成正文 | 未配置模型 | 大纲、引用、导出仍可用，可先搭结构 |
| DEPTH 分数普遍偏低 | 可能含较多「一般问题」类质疑点 | 看质疑点是否成立，区分致命缺陷与常见局限 |
| 深度审稿被判「拒稿」 | 触发一票否决（≥3 条致命缺陷） | 看质疑点列表与裁决理由，确认是否为模型误判 |
