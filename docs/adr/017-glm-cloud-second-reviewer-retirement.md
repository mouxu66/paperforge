# ADR-017: GLM 云端副评审——GLM-5.2 退役 / GLM-4.7-Flash 条件触发融合

**状态**: Accepted（已实施 · Implemented 2026-08-18，更新 2026-08-19）
**日期**: 2026-08-18（初始），2026-08-19（融合实验更新）
**关联**: ADR-014（P8 双模型交叉复核）、`mock_api/second_opinion.py`

> **⚠️ 模型版本敏感性**：本 ADR 结论高度依赖具体模型版本。GLM-5.2 的退役结论
> **不适用于** GLM-4.7-Flash。未来更换云端模型时，必须重新执行完整的校准+融合
> 实验，不可直接复用本文档的权重或阈值。

## 摘要（2026-08-19 更新）

本 ADR 覆盖两个不同模型的结论，**不可混淆**：

| 模型 | 结论 | 状态 |
|---|---|---|
| **GLM-5.2**（Z.ai 开放权重） | 输出高位堆叠、校准无效、哨兵 0 触发 → **永久退役** | 已实施 |
| **GLM-4.7-Flash**（智谱免费） | 序关系优秀（AUC=0.705）、融合后 AUC+0.066 → **条件触发融合** | 已实施 |

## 背景（Context）

### GLM-5.2 退役（2026-08-18）

GLM 云端副评审（second_opinion，云端第二评审员）经三轮验证，证据链完整闭合。结论一句话：**0.72 是 prompt 锚定；修完后 GLM-5.2 还是高位堆叠；校准救不回；哨兵 0 触发。GLM-5.2 作为「评委」或「哨兵」在当前刻度下都不成立，只能当影子记录。**

1. **prompt 锚定 bug 已修**：second_opinion 评分 prompt 曾带 0.72 锚定，导致 GLM 输出被吸向单一值；已修复（现 prompt 明确要求「按质量在全程分布，不要集中在某一值」）。本 ADR 全部 GLM 数据均为**修 prompt 后**采集。
2. **影子校准预研证明 GLM 无连续分价值**：`deliverables/glm_shadow_calibration_20260817.md`（配套 `glm_shadow_eval_20260817.json`，脚本 `scripts/calibration/glm_shadow_eval.py`）。16 篇盲评金标上 GLM 独立分 **14/16 堆叠在 0.85**，gold 0.5–0.76 区间无分辨率。留一（LOO）单调校准映射后：MAE 0.251→0.084（**均值回归假象**，14/16 预测坍缩为常数 0.658）、Cohen κ −0.016→**−0.081**（比随机还差）、Pearson r 0.673→**0.492**（退化）。**校准映射有害，救不回连续分。**
3. **全库 dry-run 证明哨兵条件不可达**：`deliverables/sentry_dryrun_full.json`（脚本 `scripts/calibration/sentry_dryrun.py`）。636 篇已完 v4.2 评审离线跑 GLM 第二评审（override 关闭，复用生产 `run_second_opinion`）：
   - cloud 分布：min=0.60 / median=0.85 / mean=0.817；`[0.8,0.9)`=449、`[0.7,0.8)`=169、`[0.6,0.7)`=17、**<0.6 为 0**；
   - 哨兵条件（cloud<0.5 ∧ local≥0.7，其中 local≥0.7 有 177 篇）**触发 0 篇**，触发率 0.0；
   - 金标覆盖 16 篇（gold_coverage=20，evaluable 16）**全部 0 触发**——补 gold 对照输出是空对照，无信息量，不补；
   - GLM 调用 635/636 成功、0 错误（仅 1 篇因无文本跳过），排除调用质量问题。

根因是 **GLM 输出高位堆叠（结构性刻度问题），不是逻辑错误**。阈值调参救不了「cloud<0.5 在全库根本不存在」的分布。

## 决策（Decision）

1. **GLM 云端副评审退役为「影子记录 + rescue 兜底」，不参与任何主链路决策**：
   - ✅ 保留 **rescue 兜底**：本地主评审未产出有效分数（JSON 解析失败/空返回）时，以云端结果兜底（flag=`rescued`），使评审以 completed 收尾而非无结果——这是唯一仍影响「是否 completed」的场景，**不改分**。
   - ✅ 保留 **cloud_shadow_score 存档**（影子分），供审计回放与未来重估。
   - ❌ 不再参与：连续分覆盖（override）、加权融合、校准映射、哨兵判定依据。
2. **P2 影子哨兵维持影子模式，不接入人工队列**：`sentry_flag` / `needs_human_review` 仅作建议标记与审计，不改变 `resolved_score`、不转人工、不阻断流程。**当前代码（`mock_api/second_opinion.py` P2 段）即此态，无需改动。** 阈值 `SENTRY_CLOUD_LOW=0.5` 在当前 GLM 刻度下不可达，触发率恒为 0——保持影子模式观察即可。
3. **暂停 GLM 校准工作**：影子预研已证明 GLM 连续分无校准价值，继续校准只会重复踩坑（κ 更负、r 退化、MAE 假象），浪费金标与算力。**重估前提**：换更强模型 / 改 prompt 使 GLM 能产出低分分布，且金标扩到 50–100 篇后分布不再 14/16 并列。
4. **金标扩样方向转向本地模型边界**（下一阶段，暂不启动）：优先 verdict 阈值附近（local_score ∈ {0.4/0.7/0.8} 附近）样本、本地低置信度（解析困难 / 内部特征分歧）样本、类别失衡的 report 样本——目的是评估本地模型在边界上的行为、微调阈值/偏移，**不是为 GLM 凑样本**。

## 边际分歧案例（人工扫一眼，非统计验证）

全库 dry-run 中 cloud=0.65 且 local≈0.8 的 2 篇（本地 accept vs 云端 major_revision 分歧），仅作分歧案例分析，理解 GLM 与本地何时产生「边际分歧」，不从中推广结论：

| pid | 论文 | local | cloud |
|---|---|---|---|
| `pr_1406.1765` | Linguistic Analysis of Requirements of a Space Project and their Conformity with the Recommendations Proposed by a Controlled Natural Language | 0.805 / accept | 0.65 / major_revision |
| `pr_1605.02442` | Machine Learning Techniques with Ontology for Subjective Answer Evaluation | 0.7875 / accept | 0.65 / major_revision |

### 人工审查框架与结论存档（2026-08-18，已由 AI 代理代审全文并填表，建议人工复核后定稿）

两篇共性：GLM 在自身刻度下给出 0.65（远高于其低分阈值 0.5），说明它对这两篇有「相对负面」信号、但认为「不够好也还不错」；本地 0.78–0.81 刚过 accept 阈值 0.8。审查时按以下三点记录：

1. **方法论是否扎实**：两篇均为偏应用/交叉领域（航天需求语言分析、主观答案评估），重点看实验规模、数据集领域性、基线对比。若人工认定确有缺陷 → cloud 0.65 部分合理，local accept 可能偏乐观。
2. **是否属「边界可上可下」**：两篇 local 都紧贴 0.8 阈值。若此类样本在库中较多 → 本地 0.8 附近校准可能不稳，是金标扩样应重点覆盖的区域。
3. **分歧是否反映维度差异**：DEPTH 拓扑评分 vs GLM 通用聊天模型（可能重语言流畅/结论明确、轻技术深度）。若 GLM 低分只因「写得不精彩」→ 其负面信号价值有限。

**结论存档**（2026-08-18 由 AI 代理代审全文后填写，非人工金标——建议人工复核这两篇判定后再定稿；结论影响判断：若判 major/reject → 本地 accept 偏高、关注 0.8 附近阈值；若判 accept → GLM 0.65 为误报、其负面信号不可靠）：

| pid | 判定（accept/major/minor） | 对本地 0.8 阈值的影响 | 对 GLM 负面信号价值的判断 |
|---|---|---|---|
| `pr_1406.1765` | **major_revision**（~0.60–0.65） | 本地 0.805 accept **偏乐观（约 +0.15 高估）** → 支持关注 0.8 附近阈值 | 0.65 方向合理、幅度略宽；支持「GLM 能识别中游偏上但实证薄」 |
| `pr_1605.02442` | **reject**（~0.45–0.55） | 本地 0.7875 accept **严重偏高（约 +0.3 高估）** → 弱实证应用论文是本地明显盲区 | 0.65 偏宽松，对真弱论文也不给低分 → GLM 低分段无刻度、负面信号幅度不足 |

**判定理由摘要**（全文细读，按「方法论扎实度 / 边界可上可下 / 维度差异」框架）：

- `pr_1406.1765`（CNES 航天需求语言分析）：真实工业语料 + 清晰动机，诚实的初步研究（自述 preliminary/first step）；但**单一项目语料子集、定性分类（mandatory/useful/undesirable）无编码一致性度量、频次差异无显著性检验、法→英泛化仅靠假设**。作为案例研究可读性好，但实证基础撑不起 accept 级严谨性。
- `pr_1605.02442`（Ontology+ML 主观题评估）：**低档期刊（IJNLC）**，方法描述混乱（MaxEnt/Perceptron 混用、「up to 90% correlation」与「improvement is not in the overall correlation」自相矛盾）、人类评分协议未定义（评分者/量表/一致性均缺）、无统计检验、无错误分析、无数据发布。技术贡献薄，只能算技术报告。

## 案例验证结论（2026-08-18）：两项关键假设得到案例级验证

两例判定直接验证了两个假设——**本地在 0.8 附近校准不稳**（两篇本地均 accept 而人工判 major/reject，高估 +0.15 / +0.3，且都压在 accept 阈值附近，是边界风险信号而非随机误差）与 **GLM 低分段无刻度、幅度不足**（第二篇人工判 reject，GLM 仅给 0.65，方向对但幅度远不够）。

| pid | local | cloud | 人工判定 | 关键问题 |
|---|---|---|---|---|
| `pr_1406.1765` | 0.805 accept | 0.65 major | **major ~0.60–0.65** | 本地在 0.8 附近高估（单语料、无编码一致性、无显著性检验） |
| `pr_1605.02442` | 0.7875 accept | 0.65 major | **reject ~0.45–0.55** | 本地严重高估（弱实证应用论文），GLM 低分幅度不足 |

**决策影响（本 ADR 追加条款）**：

1. **金标扩样策略调整——`[0.75, 0.85]` 区间列为最高优先级**：优先抽取本地判 accept 但来源偏弱（低档期刊 / 短报告 / 实验性研究）的样本。两例共性提示：**本地模型对「叙述清晰、实证薄弱」的论文系统性过度乐观**，此类样本需重点覆盖。
2. **暂不修改本地偏移或阈值**：2 例不足以重拟合 `−0.09` 偏移（ADR-011），也不临时调低 0.8 阈值。正确做法：两例作为**种子样本**入池（见下），待边界样本扩到 ≥20–30 例后再重新评估阈值/偏移。
3. **P2 哨兵维持影子模式**：cloud=0.65 方向合理，但若把哨兵阈值放宽到 0.65，全库将触发 15 条、其中仅 2 条是本地高分，误报风险不可控。哨兵**不转正**，继续影子记录不干预。
4. **种子样本入金标池（独立案例文件，不并入 calib_papers/runs）**：两例已写入 `deliverables/gold/gold_boundary_case_study_20260818.json`，标记 `gold_source=human_case_study_20260818`，后续扩样直接纳入统计。⚠️ **不并入 `calib_papers/runs/*.json`**——该目录喂 DEPTH 自动偏移估计（ADR-011），混入会污染 `−0.09` 校准。

### 批次级佐证（2026-08-18，20 篇盲评批次 AI 预评，**非人工金标**）

首批 20 篇盲评批次（`calib_papers/blind_batch_20260818_132923.jsonl`，local∈[0.75,0.85]）由独立 AI 预评（仅见摘要）后与密钥解开对照，预评存档 `deliverables/gold/gold_ai_pre_review_20260818.json`（`gold_source=ai_pre_review_20260818`，**不并入任何校准/偏移估计**）：

- **本地 19/20 判 accept，AI 预评仅 9/20 判 accept**；verdict 完全一致 8/20（40%）。
- **11 篇分歧全部是「本地 accept vs AI 预评 minor/major」**，Δ(local−AI) −0.13 ~ −0.25。
- 强论文（PATE / FeUdal / Schema Networks / coref-RL 等）双方一致 accept → 本地对真强论文判断正常，**问题集中在「中游偏上但实证/创新一般」的论文被本地拔到 accept**。
- 结论：本地在 `[0.75, 0.85]` 区间 accept 判别力接近零，方向性佐证「0.8 附近系统性高估」；但预评仅看摘要且同为 AI 判断，**只能作方向佐证与复核优先级，不能替代人工金标**。
- ⚠️ 数据异常：`pr_633` 存储判定 `reject` 与 `calibrated_score=0.777`（阈值应在 minor 区）不一致，待核。

**人工复核优先级**（11 篇分歧按 Δ 降序）：#8 pr_447（0.85 vs 0.60）、#1 pr_1704.01399（0.8475 vs 0.60）、#15 pr_1609.01188（0.835 vs 0.60）、#3 pr_767（0.82 vs 0.60）、#16 pr_1604.01729（0.85 vs 0.65）、#5 pr_1703.04854、#11 pr_387、#7 pr_1402.7015、#12 pr_1709.00489、#10 pr_1612.00094、#6 pr_678。

### 全文级复核结论（2026-08-18，AI 代理逐篇细读全文，仍非人工金标）

11 篇分歧案例全部完成全文细读，判定存档 `deliverables/gold/gold_fulltext_review_20260818.json`（`gold_source=fulltext_review_20260818`）。

- **判定分布：3/11 accept、7 minor、1 major、0 reject；本地 11/11 accept**。
- **3 篇真 accept 全部是实打实的已发表工作**：pr_447（ICLR 2017 对话提问学习）、pr_1402.7015（NeuroImage R1-GLM HRF 估计）、pr_1604.01729（EMNLP 2016 视频描述语言融合）——**本地对这些方向正确**（Δ +0.045~+0.09）。
- **8 篇高估**（Δ +0.11~+0.25）：工具/短文/渐进式改进（SBINet 葡语工具、字幕对齐、RECF、纹理长程一致性、学习率学习等），本地 0.785–0.8475 一律 accept。
- **修正预评偏差**：AI 预评（仅摘要）把 pr_447/pr_1402.7015/pr_1604.01729 判到 major/minor 是**摘要级低估**——这三篇全文审后判 accept，本地是对的。
- **核心结论修正**：问题不是「本地一律高估」，而是 **`[0.75, 0.85]` 区间本地无差别 accept（11/11），真 accept 率仅 ~27%（3/11）**；且 3 篇真 accept 的本地分全部压在带顶 0.85，8 篇高估在 0.78–0.8475。
- **0.85 阈值假说（n=11，仅作假设，勿直接改）**：本样本上「accept 阈值提到 0.85」可保留全部 3 篇真 accept 并切掉全部 8 篇高估，需 ≥20–30 例边界金标验证后再评估是否调整阈值/偏移。
- ⚠️ 本复核非盲（解开密钥后已知本地分），判定以内容/venue/实验深度为准，仍建议人工抽查。

## GLM-4.7-Flash 融合实验（2026-08-19）

### 背景

GLM-4.7-Flash（智谱免费文本模型）与 GLM-5.2（Z.ai 开放权重）是**完全不同的模型**。500 篇 PeerRead 分层抽样 + 双模型并行打分实验验证了 4.7-Flash 的融合价值。

### 实验数据

- **本地 rescore**：498/500 篇完成（Ornstein-V2 DEPTH v4 全文深度模式），`deliverables/peerread_rescore_500_base.jsonl`
- **云端 rescore**：495/500 篇完成（GLM-4.7-Flash 轻量 prompt，摘要+引言 6000 字符），`deliverables/peerread_cloud_rescore_500.jsonl`
- **有效配对**：493 篇（双方都有分数）
- **分割**：train=341 / val=70 / test=82（分层随机，seed=20260818）

### 核心结果（test set, n=82）

| 配置 | AUC | precision@0.5 | recall@0.5 |
|---|---|---|---|
| A. 本地裸分 | 0.577 | 0.420 | 0.971 |
| B. 云端裸分 | **0.705** | 0.467 | 1.000 |
| F. ridge 融合 | 0.643 | **0.524** | 0.314 |

**关键发现**：
1. **GLM-4.7-Flash 单独 AUC 已优于本地**（0.705 > 0.577）——云端序关系优秀
2. 云端分数极度量化（7 个离散值，64% 集中在 0.65），但 accept 率单调递增：0%→35.6%→56.5%→84.6%
3. **云端能力天花板**：在高分区（>0.80）云端无法区分"好"和"更好"，融合反而拖低好论文分数

### 条件触发区间扫描

| 区间 | AUC | ΔAUC | precision | API 调用率 |
|---|---|---|---|---|
| [0.60, 0.75] | 0.622 | +0.045 | 0.514 | 53.7% |
| **[0.65, 0.75]** | **0.595** | **+0.018** | 0.453 | **34.1%** |
| [0.70, 0.80] | 0.598 | +0.021 | 0.453 | 39.0% |
| [0.65, 0.85] | 0.530 | -0.047 | 0.405 | 63.4% |

**结论**：
- **生产区间 [0.70, 0.80]**：精准打击本地"高分放水"区间，AUC +0.021，API 仅 39%
- **升级路径 [0.60, 0.75]**：付费版预算充足时使用，AUC +0.045，Precision +0.061
- **上界不能超 0.80**：云端在高分区帮倒忙（量化天花板）

### 部署状态

已实现条件触发逻辑（`mock_api/second_opinion.py`）：
- 核心区 [0.70, 0.80]：总是触发云端
- 过渡带 [0.68, 0.82]：线性衰减触发概率（避免悬崖效应）
- 区间外：跳过云端，直接采信本地
- 融合公式：`fused = (1 - w_cloud × tw) × local + (w_cloud × tw) × cloud`（w_cloud=0.1）

## 后果（Consequences）

- **GLM-5.2 退役收益**：证据链固化，防止未来有人把 GLM-5.2 重新拉回主链路（改 prompt / 调阈值 / 重开 override 前必须先读本 ADR）。
- **GLM-4.7-Flash 融合收益**：条件触发模式下 AUC +0.021、Precision 翻倍，API 调用率 39%（规避 429 限流）。
- **权衡**：云端仅在边界区间出手，高分区完全信任本地全文评审；付费版可扩展触发区间至 [0.60, 0.75]。
- **注意**：本 ADR 结论高度依赖模型版本。更换云端模型时必须重新执行校准+融合实验。
