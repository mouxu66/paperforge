## ✨ 本版本新增

### 1. 首次打开自动引导（6 步）

第一次进入首页会自动弹出一段分步引导，高亮对应按钮，带你走完最常用的路径：

**导入论文 → 等待索引 → 检索 → 找到问答与审稿入口 → 帮助中心**

- 支持「上一步 / 下一步 / 跳过」，也可用 `←` `→` 切换、`Esc` 跳过；
- 引导过程中**不遮挡操作**，可以直接点被高亮的按钮真实做一遍；
- 跳过后不会重复打扰；想再看一次，去帮助中心点「重看新手引导」即可；
- 引导内容带版本号记录——以后加了关键新步骤，你会再看到一次，其余情况不重复弹。

### 2. 帮助中心（右上角 **?** 按钮，或菜单「设置 → 帮助中心」）

五个核心功能的分步教程，每节统一给三块内容：

| 章节 | 讲什么 |
|---|---|
| 导入论文 | 拖拽 / arXiv 导入 / 索引怎么等 |
| 检索 | 关键词（FTS5）· 语义 · 图检索，三种方式各自适合什么 |
| 问答 | 答案只来自你的库，引用怎么核对 |
| 写作工作台 | 项目 → 大纲 → 章节 → 导出（Word / LaTeX / Markdown） |
| 深度审稿 | 四维评分怎么读、权重为何随论文类型变、裁决四档怎么来的 |

每节都有「**你会看到**」（落到界面上可验证的观察点）和「**常见误区**」
（新手最容易误判的地方）。

### 3. 空状态引导补全

在「没数据 / 没结果 / 没配模型」时，直接告诉你下一步做什么，而不是留一片空白：

- **未配置模型**：原来只有一句提示，现在给出「去哪配 / 配哪种（云端或本地）/
  不配还能干什么」三步——并说明检索、图检索、深度审稿**不受影响**；
- **某篇论文索引未完成**：卡片上显示橙色虚线下划线，悬停说明「语义检索暂时搜不到它，
  关键词搜索与阅读标注不受影响」；
- 原有的首次使用、检索无结果等空态保持不变。

### 4. 教程文档

`docs/教程-核心功能实操.md`：与帮助中心同源，另附**常见误区速查表**
（现象 → 真正的原因 → 怎么办），适合打印或离线查阅。

## 🚀 如何开始

**Windows（最省事）**：双击项目根目录的 `start_paperforge.bat`，脚本会自动拉起后端并打开浏览器。

**其他方式**（桌面版 exe / 开发者模式 / Docker Compose）：见 `README.md` 的「快速启动」。

启动后：

1. 首页拖一篇 PDF 进「上传论文」区域，等卡片上的「文本块」从 0 变成实际数值；
2. 搜索栏切「关键词」搜个术语，确认论文在库里；
3. 想用问答 / 综述 / 写作，先到「设置 → 模型管理」配一个模型（云端填 Key，本地启动服务后检测端口）；
4. 选中论文点「V4 深度审稿」，看四维评分、质疑点与裁决理由。

遇到问题先看 `docs/教程-核心功能实操.md` 文末速查表，再看 `RUNBOOK.md`。

## 📋 自 v1.0.0 以来的其他主要变化

v1.0.0 发布后经历了较长一段开发，除本版本的新手引导与教程外，还包括：

- **DEPTH v4.2 评审严谨化**：真实金标校准、双模型复核、全文覆盖、可复核性面板；
  四维权重按论文类型动态调整，低置信度时向各类型均值平滑靠拢。
- **评分系统性偏低修复**：定位并修复配置通道失效、致命缺陷误标、分数偏移与
  裁决边界四处根因，并对存量评审记录做了分数回填。
- **实验审计（Experiment Audit）**：数字一致性、指标自洽、消融、复现性、图表轴、
  数据泄漏、图表复用等检测，含独立审计页与报告导出。
- **感悟报告链路**：六维评分、figure 级造假检测、统计红旗扣分，并修复
  「元数据影响结论」「不可测被当成 0 分」等问题。
- **前端升级与重构**：React 19 + antd 6 + zustand 5；设计系统收敛为单一主色与
  三级阴影，移除冗余装饰组件。
- **微信小程序版（MVP）**：论文导入 / 收藏 / 标签 / 笔记 / 检索 / 对比 / 引用核验。
- **安全**：仓库内学号与真实姓名已脱敏。
